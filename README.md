## Descripción

Este proyecto contiene el desarrollo de los cuatro ejercicios propuestos:

1. **Conversor de unidades** — Básico
2. **Control de asistencia** — Intermedio
3. **Menú del colmado** — Intermedio
4. **Registro de clientes** — Avanzado

---

# 1. Conversor de unidades

### Descripción

Formulario con `TextBox`, `ComboBox` para seleccionar las unidades (`km/millas`, `°C/°F`) y un `Button` que muestra el resultado en un `Label`.
