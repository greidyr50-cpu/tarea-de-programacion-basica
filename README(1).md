## Descripción

Este proyecto contiene el desarrollo de los cuatro ejercicios propuestos:

1. **Conversor de unidades** — Básico
2. **Control de asistencia** — Intermedio
3. **Menú del colmado** — Intermedio
4. **Registro de clientes** — Avanzado

---

# 1. Conversor de unidades

### Descripción

Formulario con `TextBox`, `ComboBox` para seleccionar las unidades (`km/millas`, `°C/°F`) y un `Button` que muestra el resultado en un `Label`.

# Estructura de carpetas recomendada

Para que las imágenes se muestren correctamente en GitHub, coloca el archivo `README.md` y la carpeta `images` en el mismo nivel:

```text
Proyecto/
│
├── README.md
│
└── images/
    ├── ejercicio1-conversor.png
    ├── ejercicio2-asistencia.png
    ├── ejercicio3-colmado.png
    └── ejercicio4-clientes.png
```

## Importante

Las imágenes deben estar dentro de la carpeta:

```text
images/
```

Y los nombres de los archivos deben coincidir exactamente con los utilizados en el `README.md`.

Por ejemplo:

```markdown
![Conversor de unidades](images/ejercicio1-conversor.png)
```

GitHub buscará la imagen en:

```text
README.md
     ↓
images/
     ↓
ejercicio1-conversor.png
```
